# MSAI Career Generator 🚀

An AI-powered career roadmap generator that helps users discover personalized learning paths, identify skill gaps, and explore career opportunities based on their interests and goals.

## 🌟 Features

* AI-powered career roadmap generation
* Personalized learning recommendations
* Skill-gap analysis
* Interactive and responsive user interface
* Fast and scalable web application
* Modern UI built with Next.js

## 🛠️ Tech Stack

* Next.js
* React.js
* JavaScript
* Tailwind CSS
* PostgreSQL
* Prisma ORM
* Neon Database
* Gemini API
* Vercel

## 💻 Installation

```bash
git clone https://github.com/mohdsahib-dev/MSAI-Career-Generator.git

cd MSAI-Career-Generator

npm install

npm run dev
```

## 🎯 Project Goal

The goal of this project is to help students and aspiring professionals receive AI-generated career guidance and structured learning roadmaps.
